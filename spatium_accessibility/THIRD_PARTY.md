# Third-party data

OSM data: © OpenStreetMap contributors, Open Database License (ODbL).
https://www.openstreetmap.org/copyright

The plugin requests road geometry from https://overpass-api.de only after the
user selects OSM. Query bounding boxes are sent to the provider. The provider's
availability, usage limits and policies apply. No user road layer is uploaded.

Bundled demo geometry is synthetic SpatiumLabs test data, licensed CC0-1.0;
it is not a survey, a routing-quality road network or real population data.
